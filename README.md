# Подбор инструмента qtool.ru — детерминированный поиск по каталогу сайта

Сервис принимает запрос на естественном языке («сверло 8,5 мм», «CNMG 120408», «метчик М10»,
«фреза концевая 10 мм 3 зуба») и подбирает позиции из товарных таблиц qtool.ru по всем группам:
пластины, сверла, фрезы, метчики, развертки, зенковки, державки, оснастка.

**LLM не используется.** Разбор запроса, фильтрация, ранжирование и текст ответа полностью
детерминированные: нормализация кода, парсер ISO 1832, фильтры с явной лесенкой ослаблений,
IDF-оценка совпадения слов. Один и тот же запрос всегда даёт один и тот же результат.

## Запуск на Windows

1. Распаковать архив и запустить `run.bat` (Python 3; если его нет — скачается портативный).
2. Откроется http://localhost:8000 — чат подбора. Админка: http://localhost:8000/admin.
3. Каталог сайта уже лежит в `data/catalog_site.csv`. Чтобы обновить его из выгрузок qtool.ru:
   `python refresh_catalog.py`.

Быстрые автотесты (стандартная библиотека, без сети):
`python -m unittest discover -s tests -v`. Их же запускает GitHub Actions
(`.github/workflows/tests.yml`) на каждый push и pull request.

## Каталог сайта (`/upload`)

Таблицы qtool.ru скачиваются в `data/uploads/`, читаются все листы, классифицируются разделы
и собирается единый снимок `data/catalog_site.csv` + манифест `data/site_manifest.json`.

```
python refresh_catalog.py                 # скачать свежие xlsx, ссылки из sitemap и пересобрать каталог
python refresh_catalog.py --rebuild       # без сети: пересобрать из data/uploads/*.xlsx
python refresh_catalog.py --rebuild --urls  # то же + обновить ссылки из sitemap
python refresh_catalog.py --file a.xlsx --file b.xlsx   # без сети: собрать из своих файлов
python refresh_catalog.py --json          # отчёт в JSON
```

Что делает конвейер:

- **Скачивание.** Адрес детальной выгрузки пластин содержит дату (`..._ISO_tochenie_03.11.26.xlsx`),
  каталог `/upload/` отдаёт 403, поэтому свежие даты перебираются. Общий прайс — `price.xlsx`.
  Повторный запуск использует условный GET (ETag/Last-Modified) и sha256 — неизменённые файлы не качаются.
- **Чтение XLSX** — только стандартная библиотека (`zipfile` + `ElementTree`), без pandas/openpyxl.
  Читаются все листы, ширина строки динамическая, заголовок ищется по коду Битрикса `[ATT_*]`,
  поэтому переименование русского заголовка не ломает приём.
- **Классификация.** Раздел/подраздел → группа (`insert`, `drill`, `mill`, `tap`, `holder`,
  `reamer`, `countersink`, `accessory`, …). Неизвестные разделы не размазываются по группам,
  а попадают в карантин (`unknown_sections` в манифесте).
- **Атрибуты.** Из колонок `[ATT_*]` и из названия: код ISO, форма, размер, радиус, стружколом,
  диаметр/хвостовик/длина, зубья, резьба и шаг, серия цанг, код державки, покрытие, материал.
- **Снимок.** Запись атомарная (временный файл + `os.replace`). Если новый объём меньше 80%
  предыдущего, сборка отклоняется и старый каталог остаётся на месте.
- **Ссылки.** Карточка товара берётся из `sitemap-iblock-28.xml` по ID элемента Битрикса;
  если ссылки нет — поиск по артикулу на qtool.ru.

Обновление каталога подхватывается работающим сервером без перезапуска (проверяется mtime CSV).

Если при скачивании Python не доверяет цепочке сертификатов qtool.ru (`SSL: unable to get issuer
certificate`), поставьте `pip install certifi` — код сам возьмёт его хранилище. Крайний случай,
только для доверенной сети: `QTOOL_INSECURE_TLS=1` отключает проверку сертификата.

## Как работает поиск

1. **Нормализация.** Регистр, `ё`, латиница/кириллица-омоглифы, раскладка клавиатуры,
   пробелы внутри кода (`CNMG 12 04 08` = `CNMG120408`), запятая в десятичных (`8,5`).
2. **Разбор группы и кода.** Пластина, сверло, фреза, метчик, державка, развертка, зенковка,
   цанга; код пластины (`CNMG120408`) и код державки (`PCLNR2525M12`) с защитой от ложных
   срабатываний на словах и префиксах оснастки.
3. **Параметры.** Диаметр, зубья, резьба/шаг, радиус, толщина, угол при вершине и класс длины
   сверла (`3D`/`5D`/`8D`), серия и диаметр зажима цанги, материал → группа ISO (сталь P,
   нержавейка M, чугун K, цветные N, титан S, закалка H) и вид обработки
   (черновая/получистовая/чистовая).
4. **Фильтры.** Жёсткие (код, диаметр, резьба, серия) и мягкие (зубья, ISO, обработка, марка,
   покрытие). Если точных совпадений нет, мягкие фильтры ослабляются по одному, и в ответе
   перечисляется, что именно ослаблено.
5. **Аналоги и подсказки.** Нет точного диаметра — ближайшие размеры (помечаются «аналог»).
   «Сверло под резьбу М10» — диаметр 8,5 мм и таблица подсверловки. Запрос кода державки —
   подсказка совместимой пластины.
6. **Подбор по пластине.** «Державка 2525 под CNMG1204» — все державки с сечением 25×25,
   совместимые с этой пластиной: форма и задний угол берутся из кода державки
   (`MCLNR2525M12` → форма C, задний угол N, размер 12), поэтому державки под CCMT (задний
   угол C) и другие размеры в выдачу не попадают. «Фреза 120 под APMT» — корпуса фрез,
   у которых в названии указана совместимая пластина (`под APMT1604`); если точного диаметра
   нет, показывается ближайший совместимый корпус (например, 125 мм для запроса 120 мм).
   Обороты «под пластину …», «корпус фрезы под пластину …» понимаются так же:
   «державка 2525 под пластину CNMG1204», «фреза или корпус фрезы под пластину APMT1604»,
   «расточная державка под пластину CCMT09T304» (расточные державки с дефисным кодом
   `S16Q-SCLCR09` тоже разбираются). Без группы («под пластину CNMG1204») показывается
   совместимый инструмент из всех подходящих групп; без кода пластины («фреза под пластину»)
   выдача не сужается, а в подсказках просится код пластины.
   Обратное направление — «пластина под державку MCLNR2525M12», «пластины для державки
   SCLCR2525M12»: из кода державки берутся форма, задний угол и размер пластины
   (MCLNR2525M12 → CNMG/CNMA 1204…, SCLCR2525M12 → CCMT/CCGT 1204…). Если в коде нет размера
   пластины («для державки MCLNR 2525»), сервис просит полный код, а не выдаёт всю группу.
7. **Выдача.** Дедупликация по бренду и артикулу, приоритет наличия, если точная позиция
   не в наличии — показываются позиции под заказ с явной пометкой. Несколько позиций в одном
   запросе разбираются отдельными блоками.

Пустой или слишком общий запрос («8,5», «купить») не вываливает весь склад: сервис просит
указать группу и параметры.

## Интеграция с сайтом

- `POST /api/query` — подбор. Возвращает `decision: site_search`, `llm_status: not_needed`,
  `response_text` (markdown) и карточки товаров с ценой, остатком и ссылкой на qtool.ru.
- `GET /api/status` — объём каталога, наличие, дата обновления, распределение по группам, `llm_on: false`.
- `GET /admin` — админка (локально; в публичном режиме — по `ADMIN_TOKEN`).
- `deploy/` — `.env.example`, systemd-юнит, nginx и сниппет кнопки чата для встраивания на qtool.ru.

Режимы: `ADVISOR_MODE=local` (по умолчанию, слушает 127.0.0.1) и `public` (админка только
по токену, CORS/iframe только для `ALLOWED_ORIGINS`, лимит запросов на IP). Переменные окружения
описаны в шапке `app.py` и `deploy/.env.example`.

## Проверка качества

- `python eval_site.py --verbose` — эталонные запросы из `data/site_eval.json`: группа, параметры,
  подсказки, попадание ожидаемого артикула в топ-5. Возвращает ненулевой код при расхождении.
- `python -m unittest discover -s tests -v` — приём таблиц, классификация, атрибуты, поиск по всем
  группам, гомоглифы и опечатки, лесенка ослаблений, отсутствие LLM в маршруте ответа.
- `python eval.py` — старый прогон по `data/test_dataset.json` (исторический парсер Rinscom/qtool).

## Данные

| Файл | Назначение |
|---|---|
| `data/catalog_site.csv` | единый снимок каталога сайта (все группы) |
| `data/site_manifest.json` | отчёт сборки: объёмы, группы, карантин, sha256 источников |
| `data/site_urls.json` | ID Битрикса → ссылка на карточку товара |
| `data/uploads/*.xlsx` | последние скачанные выгрузки |
| `data/site_eval.json` | эталонные запросы для `eval_site.py` |
| `data/unrecognized_queries.jsonl` | запросы, по которым ничего не нашлось (для развития словаря) |

## Ограничения

- В выгрузке qtool.ru нет части позиций (например, державок PCLNR — есть MCLN/CKJNL);
  подбор честно покажет, что точного кода нет.
- Развертки ищутся по ближайшему диаметру, если точного размера нет в наличии.
- Цены в валюте не пересчитываются: показывается исходная валюта и пометка «цена уточняется на сайте».
  Включить пересчёт по курсу ЦБ: `ADVISOR_CONVERT_FX=1`.
- Запросы про совместимость («какая державка под пластину CNMG») и аналоги обслуживает
  исторический модуль совместимости/кросс-таблиц; остальное идёт через каталог сайта.
- Подбор справочный; перед заказом сверяйте карточку товара.

## LLM

В текущем маршруте LLM не вызывается: `process_query` принудительно отключает проверку,
ответ помечается `provider: site_catalog`, `llm_status: not_needed`. Модули LLM остались
в репозитории для истории и экспериментов, но на подбор и текст ответа не влияют.
