ISSUES FIXED:
-------------
1. Search by "SCLCR09 deskar dkr" returned 11718 random items instead of ~17 SCLCR holders
2. Search by article number (site ID) and manufacturer code did not work

NEW RULES ADDED:
----------------
1. If query contains manufacturer article number or site article number -> output only that single item (exact match)
2. If query contains brand name -> output only items of that brand (hard filter)

NEW FEATURE ADDED:
------------------
3. Search for inserts by holder code:
   - "S20R-SVXCL16 пластины" -> inserts compatible with holder
   - "под S20R-SVXCL16" -> inserts compatible with holder
   - "пластины под S20R-SVXCL16" -> inserts compatible with holder
   - Works for both full holder codes (S20R-SVXCL16) and short codes (MCLNR2525M12, SCLCR09)

CHANGES MADE:
-------------
Files modified:
- src/iso5608.py: Added support for short holder codes (SCLCR09, SCLCR/L-09, MCLNR12, PWLN08, DCLN12, etc.)
  - 5-letter short codes (SCLCR09, SCLCR-09, SCLCR/L-09)
  - 4-letter short codes (PWLN08, PWLN-08, PWLN/L-08, DCLN12, DCLN-12)
  - Full external holder codes (DCLNR2525M12, DCLNR3232P12)
- src/catalog_search.py:
  - Enhanced holder_code_from_text() to tokenize slash and combine split tokens
  - Added support for 4-letter slash variants (PWLN/L 08)
  - Added _match_short_holder_code() to match against both external and internal holders
  - Fixed article number search: keep 5+ digit numbers in free_tokens
  - Added article_number field to Query with detection regex
  - Added hard filter for article numbers matching against sku and id fields
  - Fixed insert_code_from_text() to require digits in size portion (avoids matching random words like DESKAR)
  - Added holder code rejection in insert code parsing (prevents SCLCR09 being parsed as insert)
  - Brand detection: explicit "бренд/марка/производитель" OR known brand names (DESKAR, ZZKLT, OLICNC, ZEGYO) in Latin or Cyrillic
  - Brand filter changed from soft to hard (strict filtering by brand)
  - Cyrillic brand aliases: дескар, ззклт, олицнк, зеге, зегйо
  - Added stop words for insert prefixes (под, для, к, на, в, etc.) to prevent false matches
  - Added holder code rejection in _parse_compat_insert to prevent holder codes being treated as insert codes
  - Added holder->insert search: detects "holder_code пластины", "под holder_code", "пластины под holder_code" patterns
