CHANGES MADE:
-------------
Files modified:
- src/iso5608.py: Added support for short holder codes (SCLCR09, SCLCR/L-09, MCLNR12, PWLN08, DCLN12, etc.)
  - 5-letter short codes (SCLCR09, SCLCR-09, SCLCR/L-09)
  - 4-letter short codes (PWLN08, PWLN-08, PWLN/L-08, DCLN12, DCLN-12)
  - Full external holder codes (DCLNR2525M12, DCLNR3232P12)
- src/catalog_search.py:
  - Enhanced holder_code_from_text() to tokenize slash and combine split tokens
  - Added support for 4-letter slash variants (PWLN/L 08)
  - Added _match_short_holder_code() to match against both external and internal holders
  - Fixed article number search: keep 5+ digit numbers in free_tokens
  - Added article_number field to Query with detection regex
  - Added hard filter for article numbers matching against sku and id fields
  - Fixed insert_code_from_text() to require digits in size portion (avoids matching random words like DESKAR)
  - Added holder code rejection in insert code parsing (prevents SCLCR09 being parsed as insert)
